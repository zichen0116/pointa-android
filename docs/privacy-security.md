# 本地隐私、安全与权限

日期：2026-11-05。本文描述当前实现约束；安全协议尚未经过独立密码学审查，不作为正式发布认证。

## 数据

| 数据 | 用途与存放 | 删除/保留 |
| --- | --- | --- |
| 电脑名称、serverId、IPv4、证书 pin、deviceId、credential、连接时间 | 本机私有 SharedPreferences 中的 AES-GCM 密文；密钥由 Android Keystore 管理 | 忘记设备删除本机记录；卸载清理应用数据 |
| 左右手布局、主题、语言、控制方式、偏好 | 本机普通私有 SharedPreferences | 应用清除数据或卸载 |
| 相机预览帧和二维码内容 | 仅在扫码页面的内存中解码；QR含短期配对秘密 | 扫描结束释放；不存相册、不上传、不记录日志 |
| 指针坐标、翻页、激光参数、心跳 | 与选定 Windows 电脑间的 TLS/WebSocket | 连接结束丢弃待发控制；不跨连接重放 |
| 手机旋转向量 | 空中指针按住期间在本机计算相对位移，只传归一化坐标 | 松手注销传感器，不记录或上传原始传感器数据 |
| 发现广播 | 局域网候选电脑与过期时间；无凭据和设备码 | 仅作为未验证的候选地址 |

无账号、广告、分析 SDK、遥测上传或演示内容采集。开发调试工具产生的报告、截图和测试邀请应留在忽略的 artifacts/captures 目录，不应提交配对码、token、credential、私钥或包含它们的截图。

Keystore 不保证所有设备都采用独立安全芯片，本实现不把硬件保护作为宣传承诺。设备遭 root、操作系统被攻破或用户主动泄露配对凭据不在应用层加密可完全解决的范围。加密数据损坏、密钥丢失时保留原记录并提示，禁止默认为空列表后覆盖。

`allowBackup=false`、`fullBackupContent=false` 与 Android 12+ `data_extraction_rules.xml` 排除云备份/设备迁移中的私有记录。开发版不自动导出信任或将凭据放入剪贴板。

## 最小权限

| Manifest 权限 | 用途 | 请求时机 |
| --- | --- | --- |
| INTERNET | 与电脑建立局域网 WSS；不代表有云端服务器 | 安装声明 |
| ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE | 当前网络与局域网发现辅助 | 安装声明 |
| CHANGE_WIFI_MULTICAST_STATE | 发现期间保留局域网数据接收能力 | 发现期间使用，完成后释放 |
| CAMERA | 扫描电脑上的配对 QR | 用户进入扫码时请求；拒绝后可用设备码 |
| VIBRATE | 可关闭的短促触觉反馈 | 安装声明 |

无位置、通讯录、麦克风、存储读写、无障碍服务、悬浮窗、设备管理或后台常驻服务权限。相机硬件声明为可选；没有相机/陀螺仪的手机仍可通过手输 IP+设备码使用触控与翻页。

## 配对、遗忘和后台

QR/设备码只建立候选身份，Windows 明确批准后才生成可重连凭据。扫码 pin 对完整 DER 叶证书计算；设备码使用实际 TLS 证书绑定的 SRP 互证；已知电脑证书变化必须重新显式配对。

“忘记”会移除本机保存的记录；若当前已连接，可发送 `device.forget` 让 Windows 同时撤销。对离线电脑无法承诺远程撤销已送达；可在 Windows 的设备管理中删除该手机。Windows 撤销、断开和超时均隐藏指针，客户端不恢复旧控制队列。

应用进入后台或锁屏时停止指针与演示控制；常亮选项只作用于前台。相机仅在扫码期间启动。真正的网络瞬断由心跳超时识别，Windows 最迟约下一维护周期隐藏，而不是声称物理断网瞬间获知。
