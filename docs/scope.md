# Android 0.1.0 范围与验收映射

本表区分本轮实现目标和发布前实测；“纳入”不等于真机验收通过。具体执行结果只记在 [validation.md](validation.md)。

| PRD / V5 | 本轮范围 | 验证方法 |
| --- | --- | --- |
| F-AND-01 扫码配对 | CameraX 扫描 Pointa QR；首次扫码请求相机权限；显式 PC 批准 | URI/证书 pin 测试；真实二维码+相机真机待测 |
| F-AND-02 设备码 | 局域网发现与手动 IP；certificate-bound SRP-6a | Java ↔ Windows 真实 SRP；错误设备码与绑定拒绝 |
| F-AND-03 最近设备 | Keystore 保护凭据；受信电脑重连、断开、忘记 | 存储/状态测试；撤销后拒绝重连 |
| F-AND-04 / V5 单手 | 相对触控、镜像左右手、独立四边草稿、侧栏联动、布局锁定 | 几何边界测试；手机触达与编辑实测 |
| F-AND-05 全屏 | 绝对坐标为默认；可选相对映射；按目标显示器比例拟合 | 角落映射、缺失尺寸与热插拔更新测试 |
| F-AND-06 外观 | 主题与激光色分离、大小、拖尾、平滑、灵敏度 | 偏好边界、服务端 effect.applied/rejected |
| F-AND-07 / V5 翻页 | 上一页/下一页、纯翻页、可关闭振动、音量键映射与冲突处理 | UUID 去重、冷却、断连不重放；焦点实测 |
| F-AND-08 状态 | 真实连接/批准/失败反馈、可选常亮、后台停止输出 | 生命周期测试、静默超时隐藏；锁屏/切网实测 |
| F-AND-09 语言 | 中英/跟随系统、深浅色、六种强调色、可跳过引导、减少动画 | Compose/模拟器；TalkBack与极端字号待测 |
| F-AND-10 空中指针 | P1，暂不提供可操作模式 | 两类传感器真机校准与漂移实测后实施 |
| NFR 延迟/兼容/续航 | 不以测试主机代替硬件结果 | 两类手机+两类Windows配置；≥100次录像测P95；长时间演示 |

连接只支持局域网 IPv4；无 mDNS、IPv6、远程互联网转发和 iOS/Web 客户端。应用不采集或传输幻灯片图像，无法判断真实总页数。Windows 激光覆盖层在共享整个屏幕与只共享应用窗口时的可见性不同，仍以现有 Windows 说明为准。
